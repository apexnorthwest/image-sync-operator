# Security and Vulnerability Reports
The maintainers of this project endeavor to provide secure, maintained, and
reliable software. To this end, any reports of exploits, vunerabilities,
or compromised dependencies are taken very seriously.

Should you find a vulnerability that is in the source code of this project,
you should notify the maintainers via <admin@apexnorthwest.com>. Any reported
vulnerability shall be fixed and disclosed within 30 days of the report.

In the event there is a vulnerability in one of the dependencies of this 
project, there are two possible paths. If that vulnerability is not already
publicly disclosed, you should report it as described above. If it is instead
already publicly disclosed and a fix is available, you should open a normal
issue on the project with the appropriate information if one  does not already
exist.

Should any severe vulnerabilites be discovered at any time in this project,
the affected versions and fixed versions will be listed below this line.
